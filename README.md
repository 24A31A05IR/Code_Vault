# LeetCode Solutions

A collection of LeetCode problems solved while preparing for coding interviews and placements.

This repository is used to practice Data Structures and Algorithms, improve problem-solving skills, and understand different approaches to solving coding problems.

* Strings
* Hashing
* Two Pointers
* Sliding Window

* Binary Search

* Stacks and Queues
* Trees
* Graphs
* Greedy Algorithms
* Dynamic Programming
* SQL

## Languages

* Python
* SQL

## Automatic Updates

LeetCode solutions are automatically pushed to this repository whenever a problem is solved.

This keeps the repository updated without manually uploading each solution.

## Purpose

The main focus is not just solving more problems, but understanding the logic and patterns behind them.

This repository tracks the progress of learning, practicing, and improving problem-solving skills for placements and technical interviews.

## Goal

Keep solving. Learn from mistakes. Improve with every problem.
